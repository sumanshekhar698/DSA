Now, Why is Height = log₂(n)?
▶️ In a perfect binary tree:
Each level doubles the number of nodes.

Level	Nodes at that Level
0	    1
1	    2
2	    4
3	    8
...	...
h	    2^h



n = 1 + 2 + 4 + 8 + ... + 2^h
  = 2^(h+1) - 1



n ≈ 2^(h+1)
=> log₂(n) ≈ h + 1
=> h ≈ log₂(n) - 1
